# Planet Class

This lab implements a Planet class in Python to practice object-oriented programming, input validation, instance attributes, instance methods, and string representation.

## Requirements

The project defines a Planet class with the following behavior:

- Stores the planet name, planet type, and the star it orbits.
- Validates that all input values are strings.
- Raises a TypeError when any input value is not a string.
- Raises a ValueError when any input value is an empty string.
- Provides an orbit() method that returns a sentence describing the planet's orbit.
- Defines a __str__() method to display the planet information in a readable format.
- Creates and tests three planet instances.

## Concepts Practiced

- Classes and objects
- The __init__ constructor
- Instance attributes
- Instance methods
- Error handling with TypeError and ValueError
- The __str__ special method
- Object instantiation

## Expected Output Format

```text
Planet: Earth | Type: Terrestrial | Star: Sun
Earth is orbiting around Sun...
```
